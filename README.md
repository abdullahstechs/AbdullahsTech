# Abdullahs Tech Android starter

This is a starter Android project with a dark navy/orange shop UI, sample JBL-inspired products, search, category filters, favorites, a cart, quantity controls and a demo checkout screen.

## Important
- Prices and products are sample data. This is not a real store.
- Checkout is a visual demo. It does not take payments.
- Do not enter or store real card numbers or CVC values in this app.
- To accept real payments, add a supported provider SDK and a secure backend. Payment sessions and secrets must be created server-side.
- Product names and trademarks belong to their respective owners; only list products you are authorized to sell.

## Build
Open this folder in Android Studio, allow Gradle sync, then select Run.
To build an APK, use Build > Build APK(s). The debug APK is for testing, not Google Play release.
